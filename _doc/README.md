# _doc

项目文档统一放在本目录。维护约定见仓库根目录的 `AGENTS.md`。

| 子目录 | 职责 |
| --- | --- |
| `changelog/` | 变更记录。每次改动更新 `SUMMARY.md`。 |
| `projectinfo/` | 本应用的目录、模块、技术栈。 |
| `plan/` | 较复杂功能的实现方案。 |
| `testcase/` | 测试方案和用例。 |
| `参考资料/` | 外部 API、第三方文档。 |
| `输出文案/` | 设计说明、演进记录等。 |
| `aicode/rules/` | 运行时选型与本机查找见 `runtime.md`。发布前自检见 `publish_check.md`。也可放本项目自定规范。 |
| `aicode/examples/` | 本应用参考实现（可选）。 |
