# 首版可重复验收

## 自动化

使用平台 Node 24 执行 `npm test` 与 `npm run build`。服务集成测试在系统临时目录建立独立数据库、使用动态本机端口，结束后删除，不触碰用户数据。

## 浏览器操作

1. 在开发测试用 TOPARROW_DATA_DIR 执行 `npm run generate -- 100000`，预期 100000 请求、100 IP、20000 个 499、102400000 响应字节。
2. 通过顶箭打开应用，选择生成文件。导入中滚动页面、点击导航，界面应能响应；完成后核对指标。
3. 点击热门路径柱，进入日志检索，路径标签为精确匹配；手动编辑后改为包含搜索。组合 IP、状态码筛选，核对每页最多 50 行。
4. 展开一行，核对文件名、原文与 UA，测试复制。刷新页面，数据仍应存在。
5. 同时选择 examples/combined.txt 和其 gzip 版本，应得 6 请求、2 IP；新增一条无效行，应报告 1 条失败且仍保留 6 条有效请求。
6. 再次导入大文件，在导入中途取消，报告应显示取消，刷新后不能将部分数据当成完整数据集。
7. 导入纯错误文本、空文件、损坏 gzip，均应显示可操作的错误而非空白页。
8. 删除数据集，确认导入列表及选择框移除它；测试服务重启后的正常数据读取和未完成导入恢复。
9. 在 1440×900、1366×768 检查布局，切换浅色主题与折叠侧栏。

2026-11-02 macOS Chrome 已验证十万行、多文件/gzip、部分错误、分页、原文、图表精确钻取、取消回滚、刷新持久化、删除以及两个尺寸；未进行 Windows 实机或百万行验收。

## 自适应格式验收

- 选择文件后先出现格式预览，确认后才导入；取消预览不创建数据集。
- 同时选择 extended.txt 和包含 ip/time/request/status/bytes 的逐行 JSON 文件，自动识别并联合导入。
- 自定义 `|` 分隔的日志应先提示无法自动识别；切换 log_format 并粘贴对应变量后预览成功，核对字段再导入。
- 输入缺关键变量、相邻无分隔符变量或不匹配规则，应提示原因并禁止无有效预览的导入。
- 刷新应用，下一次导入默认复用最近成功导入的规则；可切回自动识别。
- 样本预览仅检查有限行，不宣称全文件格式都已验证；完整导入仍报告失败行。

## 上游多值耗时

自动识别或配置中文模板后，导入含 `响应耗时=0.223 : 0.136 连接耗时=0.000 : 0.000 首包耗时=0.223 : 0.136` 的日志，应成功解析为单条请求。详情显示各段毫秒并保留分隔符；总览仍使用总耗时字段。逗号、冒号混合和列表中的 - 均支持；列表尾部分隔符、非法文本和多值总耗时应报告错误。旧数据集不自动修补，需要重新导入原始文件。

## 时间检索

填写起止时间后点击“应用时间”或按回车；已应用提示必须与实际查询一致。使用 12:30:00、12:30:59.999、12:31:00、15:07:06 四条测试日志，筛选到 12:30 分钟时只返回前两条。输入精确到秒时包含该秒内所有毫秒。反向或未完成时间不能发起查询。重置必须同时清除已应用条件和未应用草稿；时间区间没有日志时展示零结果。图表钻取仍应同步更新输入与已应用范围。

日期与时间分开选择后：日历只负责日期，独立下拉可选 00–23 小时、00–59 分钟和秒。选同一天、不改时间后应用应查询整天；随后选定时分秒应缩小范围。未选日期却修改时间时应明确提示；单侧清除与全部重置都应同步控件和条件。

一体式日历验收：点击开始/结束时间框，在同一弹出面板选择年份、月份、日期及三个时间滚动列，点确定后输入框显示完整时间，点应用时间检索。核对选中数值可见、视口底部可访问确定按钮、Escape/外部点击关闭和重置；筛选栏不再直接展示各个时间选择控件。

## 独立运行包

执行平台 Node `--test scripts/verify-package.mjs`（或 npm run check:package），不需要开发依赖。脚本临时复制 manifest.json/server.mjs/public，从独立目录启动，确认健康检查、首页、所有页面资源及 Worker 成功响应、SQLite 仅写测试数据目录；缺 public 时健康 503、首页中文说明。重新顶箭打包后核对安装目录含 public/index.html 与 public/assets，再实际打开、导入一份示例日志；运行包无需 src/node_modules/dist。

## 同名导入

准备两个名称相同、时间相同、请求数不同的历史数据集，下拉应显示不同次数标签，分别选中应返回正确数据。再次选择同名文件，预览默认“原名（2）”并提醒另存，可自定义名称；确认后旧数据不变。刷新再次同名导入应顺延（3）。空名称不能导入，解析报告和当前名称与列表一致。
