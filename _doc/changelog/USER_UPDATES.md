# 用户可见的更新

- 2026-11-03 安装包内置应用图标，供市场列表和客户端识别展示。

- 2026-11-02 准备深蓝色日志与趋势线应用图标，用于应用市场展示。

- 2026-11-02 发布包不包含开发导入记录，补齐开源许可；服务仅本机访问，首次运行从空数据开始。

- 2026-11-02 同名日志不再混淆：已有记录显示时间和次数，新导入自动加序号，也可以自己命名。

- 2026-11-02 数据集、起止时间和按钮整齐排列，筛选栏更紧凑，小窗口自动换行。

- 2026-11-02 修复打包安装后无法打开页面的问题，页面资源现已随运行包一起提供。

- 2026-11-02 点击时间框即可在同一个日历面板选年月日、时分秒，筛选栏恢复为紧凑布局。

- 2026-11-02 时间筛选可用日历选日期、下拉选时分秒；只选日期默认整天，并可单独清除起止条件。

- 2026-11-02 时间输入后可点击“应用时间”或按回车筛选，并清楚查看已应用范围；结束分钟/秒完整包含。

- 2026-11-02 可从导入记录点击文件名或“查看分析”打开日志图表，自动清除旧筛选。

- 2026-11-02 带多个上游耗时的日志也能导入，详情可查看每段耗时，不再误报为无效耗时。

- 2026-11-02 导入前可预览识别结果；遇到自定义格式可粘贴 Nginx log_format，后续导入自动复用。

- 2026-11-02 支持导入带四项耗时及中文字段名的日志；可查看平均总耗时和单条请求耗时，缺失值显示无数据。

- 2026-11-02 可导入多个 Nginx 日志或 gzip 文件，查看访问趋势、热门 IP/路径、状态码并检索原始请求，数据保留在本机。
