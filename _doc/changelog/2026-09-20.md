# 2026-09-20

顶箭平台从 0.3.6 起内置 embeddable CPython 3.13，本模板同步放开 Python。

## 改了什么

- `AGENTS.md`：运行时列表加上 Python；健康检查与端口约定覆盖 PHP / Node / Python。仍不支持 Java。
- `_doc/aicode/rules/runtime.md`：选型表增加 Python；本机查找补 `runtime\python\python.exe`；写明 vendor、禁止 `.venv` / 自带解释器、平台不内置 pip。
- `_doc/projectinfo/overview.md`、`_doc/plan/README.md`：运行时枚举与查找说明跟上。

## 给后续开发的注意

选 Python 时 `manifest.json` 的 `runtime.type` 填 `python`，`entry.main` 填入口 py。第三方库用 `pip install --target vendor` 展开进应用，不要在用户机器上现装。
