# LogScope 首版确认方案

## 背景与目标

将现有解析、查询与存储骨架整合为顶箭本机可运行的真实日志工作台。只实施产品指令 Phase 1，另按用户确认提前支持多文件及 gzip；纯中文。

## 技术方案

React/TypeScript/Vite + ECharts；平台 Node 24 仅提供本地页面与 SQLite 存取，不处理日志分析。浏览器 Worker 进行词法解析、流式解压、UTF-8 分块、筛选及聚合。运行数据保存在 TOPARROW_DATA_DIR，服务监听 TOPARROW_APP_PORT 的 127.0.0.1。因浏览器存储随来源变化，按用户授权用 SQLite 替代 IndexedDB。

## 涉及模块

工作台布局、导入状态、概览图表、日志检索、原文详情、数据集管理；核心代码分离为 app/components/parsers/workers/analytics/storage/types/tests；server.mjs 为平台入口。

## 验收与注意事项

十万行真实浏览器导入需保持响应且统计符合独立预期；自动化验证时间偏移、499、IPv6、跨块、取消、错误行与持久化恢复。仅支持标准 Combined，缺少耗时显示无数据，不提前实现异常识别、爬虫识别和导出。不上传日志，不加载外部资源，不声称未经验证的文件规模与平台表现。
